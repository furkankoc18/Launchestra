# Launchestra 0.1.0 Beta 1

Durum: yerel beta adayı. Developer ID imzası, notarization, public depo ve release yayını henüz tamamlanmadı.

## İçerik

- Uygulama, klasör ve HTTP(S) adreslerinden çalışma profilleri oluşturma.
- Profil çoğaltma, silme, sıralama ve eylem düzenleme.
- Menü çubuğu ve isteğe bağlı global kısayoldan sıralı çalıştırma.
- Tek run kapısı, eylem/toplam zaman aşımı, iptal ve ayrıntılı sonuç görünümü.
- İsteğe bağlı girişte başlatma; otomatik profil çalıştırma yok.
- Türkçe/İngilizce ilk açılış ve arayüz.
- Sürümlü yerel JSON, atomik yazma, backup, kullanıcı kontrollü kurtarma.
- Gizlilik sınırlı yerel OSLog tanılaması.

## Bilinen sınırlar

- İlk aday yalnız Apple Silicon ve macOS 14+ hedefler.
- Fiziksel test cihazı macOS 26.6.2 çalıştıran Mac16,7'dir; macOS 14 cihaz koşusu bekliyor.
- Uygulama macOS'un açma isteğini kabul ettiğini raporlar; hedefin tamamen hazır olduğunu izlemez.
- URL açmak varsayılan tarayıcıda ağ isteği oluşturabilir; Launchestra URL kaydederken içerik indirmez.
- Shell/Terminal, AppleScript, pencere yerleşimi, monitör/ses otomasyonu, import/export ve otomatik güncelleme yoktur.
- Yerel paket ad-hoc imzalıdır. Developer ID/notarization tamamlanmadan public beta olarak dağıtılmamalıdır.

## Veri uyumluluğu

Kullanıcıya görünen ad Launchestra, bundle kimliği `io.github.furkankoc18.Launchestra` değeridir. Profil verisi mevcut geliştirme kopyalarıyla uyumluluk için `~/Library/Application Support/DeskMode` içinde kalır. Schema sürümü 1'dir.

## Doğrulama özeti

- Swift package: 71 test, warnings-as-errors.
- İmzalı Debug UI regresyonu: 15 senaryo.
- Release 50 × 30 fixture profil görünümü: 30 ölçüm; ayrıntı performans raporunda.
- 5 dakika idle kaynak ölçümü: ayrıntı performans raporunda.

Checksum ve yerel artifact bilgileri paket üretiminden sonra `dist/0.1.0-beta.1/SHA256SUMS.txt` içinde oluşur. Bu dizin üretilmiş çıktı olduğu için Git'e eklenmez.
